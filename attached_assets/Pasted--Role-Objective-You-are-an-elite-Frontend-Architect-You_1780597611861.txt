# Role & Objective
You are an elite Frontend Architect. Your task is to refactor our web application to mirror the high-end, minimalist technical aesthetic of the "Hermes Agent" website (hermes-agent.nousresearch.com).

## 1. Design Language (The "Hermes" Aesthetic)
*   **Typography:** Use a strictly sans-serif, high-legibility font stack (e.g., Inter, Geist, or IBM Plex Mono for technical headers).
*   **Color Palette:** Use a "Deep Technical" theme:
    *   **Backgrounds:** #000000 (true black) or #0a0a0a.
    *   **Text:** High-contrast white/off-white for headers, muted gray (#a1a1aa) for body text.
    *   **Accents:** Single-color accents (e.g., subtle blue or monochromatic borders) instead of flashy gradients.
*   **Layout Style:**
    *   **Ultra-Minimalist:** Use wide margins, generous whitespace (padding), and clean container widths.
    *   **Bento-Grid / Card System:** Organize features in a grid of cards with subtle, 1px thin borders (#27272a).
    *   **Fixed Elements:** Keep navigation clean and subtle. Use mono-spaced font for CLI-like snippets.

## 2. Structural Requirements
*   **Landing Page:** Focus on a strong central headline, a "One-line" install/get-started snippet (Terminal-style box), and clean feature columns.
*   **Authentication:** The Login/Logout flow must be a clean, centered modal or page that matches the site’s monochromatic, minimal look—no distracting visuals.
*   **Interactive Tool:** The protected "Tool" workspace should look like an advanced developer interface—think "Dashboard" rather than "Webpage." Use terminal-like aesthetics for outputs and clear, structured layout modules.

## 3. Key UI Features to Replicate
*   **"Terminal" Snippets:** Use a dark, border-heavy component to display code snippets or CLI commands.
*   **Visual Balance:** Avoid over-decoration. Let the typography and the quality of the content speak for itself.
*   **Navigation:** Minimalist header with discrete links (Home, About, Docs, etc.) and a high-contrast login/logout button that matches the primary brand color.

## 4. Technical Stack Implementation
*   **Styling:** Use Tailwind CSS to strictly enforce the "Hermes" spacing and grid systems.
*   **Micro-interactions:** Use very subtle hover effects (e.g., border color shift or brightness increase) rather than bouncy or aggressive animations.
*   **Responsiveness:** Ensure that on mobile, the bento-grid collapses into a single, elegant vertical column.

---

## 5. Execution Plan
1.  **Refactor Global CSS:** Apply the "Hermes" dark-mode theme, typography, and spacing constants.
2.  **Rebuild Navigation:** Clean up the existing Navbar to match the minimalist, clean link style.
3.  **Modernize Hero/Features:** Rewrite existing components into the "Hermes" bento-grid layout.
4.  **Implement Auth & Tooling:** Style the Login/Logout pages and the Tool dashboard to be functional, industrial, and distraction-free.

Review the existing code and start by applying the core dark-theme design system. Let's make it look like a high-end developer tool.
