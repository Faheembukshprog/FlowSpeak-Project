## 2. UI/UX & Interactivity Requirements (Make it Alive)
*   **Micro-interactions:** Add smooth transitions, scaling, or depth changes (`box-shadow`) on cards, buttons, and links when hovered.
*   **Scroll Animations:** Implement fade-in, slide-up, or stagger animations as the user scrolls down the page (using simple CSS Intersection Observer or Tailwind transition classes).
*   **Dark Modern Aesthetic:** Prioritize a sleek, dark-mode-first tech aesthetic (e.g., deep slates/grays, rich blacks) accented with sharp, vibrant accent colors (e.g., electric blue, neon violet, or emerald green) to signify cutting-edge technology.
*   **Glassmorphism/Modern Textures:** Use subtle backdrop blurs (`backdrop-blur-md`), fine borders, and gradient text masking where appropriate to make the UI look premium.

---

## 3. Technical Constraints & Code Quality
*   **Responsive Architecture:** Ensure flawless layouts across Ultra-wide monitors, Laptops, Tablets, and Mobile screens (Mobile-first or strictly fluid design).
*   **Clean Code Principles:** 
    *   Maintain strict semantic HTML structure.
    *   Use modular component architecture.
    *   Ensure all components are strictly typed if utilizing TypeScript.
*   **Performance:** Optimize image loading, utilize CSS transitions over heavy external libraries where possible, and avoid blocking scripts.
